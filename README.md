# Speed Catch

A simple browser arcade game built with HTML, CSS, and JavaScript.

## Controls
- Move Left: `ArrowLeft` or `A`
- Move Right: `ArrowRight` or `D`

## Gameplay
- Catch falling yellow stars to increase your score.
- Missing a star costs 1 life (3 lives total).
- Click **Restart Game** to play again after Game Over.

## How to Run
Open `index.html` in any web browser.
